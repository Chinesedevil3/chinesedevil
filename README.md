# 333 Nuggets

**Mint RAW. Cook your Nugget. Face your fate.**

333 Nuggets is a collectible NFT experiment built around one simple interaction: a RAW nugget can be cooked once, revealing either a COOKED or BURNT outcome.

## The idea

- **RAW** is the starting state.
- **COOK** triggers a one-time transformation.
- The result is **COOKED** or **BURNT**.
- The result is intended to be irreversible.

## Prototype status

This repository currently contains an interactive front-end concept demo. The cook result is simulated in the browser and is **not yet an on-chain transaction**. NFT minting, smart-contract enforcement, wallet connection, and deployed contract verification remain future implementation steps.

## Run it

Open `index.html` in a browser. No build step is required.

## Why Nuggets?

A tiny, silly collectible with a clear mechanic: you don't just collect a nugget, you decide to cook it and live with the outcome.

Built as an experimental project for the Monad ecosystem.
